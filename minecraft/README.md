# Сборщик модов для Prism Launcher

Пишешь, какую сборку хочешь, программа находит моды, скачивает их и собирает один файл для Prism.

## Как пользоваться
1. Поставь Python с python.org (при установке отметь «Add Python to PATH»).
2. Скачай папку `minecraft`, запусти `Запуск.bat` (или `python zeksi_modpack.py`).
3. Напиши желания через запятую: `магия, оптимизация, шейдеры, create, миникарта`.
   Жанры (магия, техно, приключения, еда, мобы, декор...) программа подбирает сама, а всё остальное ищет как название мода.
4. Выбери версию Minecraft и загрузчик (Fabric, Forge, NeoForge), нажми «Собрать».
5. Два способа получить моды:
   - **Сразу в лаунчер:** нажми «Выбрать» у папки экземпляра (в Prism: правый клик на сборке → «Папка»), потом «Положить моды в папку экземпляра». Версия и загрузчик подставятся сами, если это экземпляр Prism. Подойдёт любой лаунчер, где есть папка `mods`: программа просто кладёт туда файлы и ничего чужого не удаляет.
   - **Новая сборка в Prism:** «Собрать файл для импорта», потом Добавить экземпляр → Импорт → выбери `.zip`.
   Версия игры и загрузчик экземпляра должны совпадать с теми, что выбраны в программе.

## CurseForge
Сначала ищем на Modrinth (ключ не нужен). Если мода там нет, берём с CurseForge. Для этого нужен бесплатный ключ: console.curseforge.com → вход → API keys. Ключ сохраняется только на твоём компьютере (`~/.zeksi_modpack.json`).
Если автор запретил скачивание программами, мод попадёт в отчёт со ссылкой для ручной загрузки.

## Проверка
`python test_modpack.py` проверяет логику на подставных данных, без интернета.
