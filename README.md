# Игровой хаб

Все игры в одном месте. Листаешь свайпом, нажимаешь «Играть».

- **СЛОВОПАД:** печатай слова, пока они не упали
- **Стопка:** башня из блоков одним касанием
- **Словозмей:** змейка ест буквы и собирает слова (скоро)
- **Notely:** бесплатная музыка

Открывается на телефоне, планшете и компьютере. Ставится на экран «Домой» и работает как приложение.
