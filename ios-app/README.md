# Приложение «Игры» для iPhone и iPad

Оболочка, которая открывает игровой хаб на весь экран. Хаб и игры обновляются сами, как сайт.
Приложение собирается без подписи. Подпись ставит Sideloadly, когда ты ставишь файл на телефон своим Apple ID.

1. Скачай `Igry.ipa` со страницы [релиза](https://github.com/Felykxzy/felykxzy.github.io/releases/tag/ios-latest).
2. Подключи iPhone к компьютеру кабелем, на телефоне нажми «Доверять».
3. Открой Sideloadly, перетащи файл `.ipa`, выбери iPhone, впиши Apple ID, нажми «Start».
4. На iPhone: «Настройки» → «Основные» → «VPN и управление устройством» → свой Apple ID → «Доверять».
5. Если просит: «Конфиденциальность и безопасность» → «Режим разработчика» → включить.

Бесплатный Apple ID держит подпись 7 дней, потом снова нажми «Start» в Sideloadly.
