# Cube Form

Мод для Minecraft 1.21.1 (Fabric). Превращает тебя в куб с частицами.

- Команда `/cube` (подходит для телефона) или клавиша **V**.
- Если в руке блок, ты станешь этим блоком. Иначе золотым.
- Нужен Fabric Loader и Fabric API.

Скачать: раздел Releases, файл `.jar` положить в папку `mods`.
