# Cube Form

Мод для Minecraft 1.21.1 (Fabric). Ты сам превращаешься:

- в воде: лодка;
- идёшь или прыгаешь: обычный игрок;
- стоишь на месте (около секунды): блок, на который смотришь (иначе блок под ногами).

Команда `/cube` (подходит для телефона) или клавиша **V** включает и выключает мод.
Нужен Fabric Loader и Fabric API. Скачать: раздел Releases.
